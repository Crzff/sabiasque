Política de privacidad de ShortsFactory

Última actualización: 20 de octubre de 2026.

Qué es

ShortsFactory es una aplicación personal que su propietario ejecuta en su propio ordenador para subir y programar vídeos en su canal de YouTube. No tiene usuarios externos.

Datos de Google que usa

Con el permiso del propietario, la aplicación usa la API de datos de YouTube para:

  • subir vídeos al canal del propietario y programar su publicación (youtube.upload);
  • leer el nombre y el identificador de ese canal para confirmar que es el correcto (youtube.readonly).

Almacenamiento y uso compartido

El token de acceso se guarda solo en el ordenador del propietario, en un archivo con permisos restringidos. La aplicación no envía datos de Google a ningún servidor propio ni a terceros, no los vende y no los usa para publicidad. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
